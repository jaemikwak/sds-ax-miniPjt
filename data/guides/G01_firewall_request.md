# 방화벽 오픈 신청 절차

원큐(OneQ) 업무시스템 서버(개발·스테이징·운영)에 새로 접속해야 할 때 방화벽 오픈을 신청하는 방법입니다.
"IP 열어 주세요", "원큐 서버 접속이 안 돼요", "포트 열어 주세요" 같은 요청은 모두 이 절차를 따릅니다.
서버 호스트명·IP는 G17(원큐 아키텍처 구성 및 서버 정보)을 참고하세요.

## 1. 신청 전 준비
- 출발지 IP(사용자 PC 또는 서버 IP), 목적지 서버 호스트명/IP, 포트, 프로토콜(TCP/UDP)을 확인합니다.
- 원큐 개발서버 목적지: `ONEQ-DEV-01`(10.30.1.11) — 원격 접속 RDP **3389**, WAS 테스트 **8080**, 웹 443
- 스테이징: `ONEQ-STG-01`(10.20.1.11) — 443, 8080
- 운영서버(`ONEQ-PRD-*`)는 개인 PC에서 직접 신청할 수 없고, 점프서버(`JUMP-PRD01`) 경유만 허용됩니다.

## 2. 신청 방법
1. ITSM 포털 → [서비스 요청] → [네트워크] → **방화벽 오픈 신청** 양식을 엽니다.
2. 출발지/목적지/포트/사용 기간(최대 1년)을 입력합니다. 사용 목적은 구체적으로 적습니다.
3. 결재선: 신청자 → 신청자 소속 팀장 → 시스템운영팀(원큐 운영 담당) 검토 → 인프라보안팀 방화벽 정책 승인(서하린 책임).
4. 승인 후 영업일 기준 **2일 이내** 반영됩니다. 반영 완료 시 ITSM 알림 메일이 발송됩니다.

## 3. 운영 담당자 확인 사항
- 시스템운영팀은 목적지 서버와 포트가 원큐 서비스 구성(G17)과 맞는지 확인하고 검토 의견을 남깁니다.
- 운영서버 직접 접속 요청은 반려하고 점프서버 경유 방법(G06 참고)을 안내합니다.
- 방화벽이 열려도 서버 Windows 계정이 없으면 RDP 로그인이 안 되므로 서버 계정 신청(G06)도 함께 안내합니다.

## 4. 자주 묻는 질문
- Q. 급하게 오늘 열어야 합니다. → 긴급 오픈은 팀장 승인 사유를 첨부하면 당일 반영 가능(인프라보안팀 당직 확인 필요).
- Q. 기존에 열려 있던 정책을 닫고 싶습니다. → 방화벽 정책 해제 절차(G02)를 따릅니다.
