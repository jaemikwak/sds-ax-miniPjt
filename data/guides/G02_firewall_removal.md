# 방화벽 정책 해제·회수 절차

더 이상 쓰지 않는 방화벽 정책을 닫거나, 퇴사·전배자의 접근 정책을 회수하는 절차입니다.
신규 오픈은 G01(방화벽 오픈 신청 절차)을 참고하세요.

## 1. 해제 대상
- 사용 기간이 만료된 정책, 프로젝트 종료로 불필요해진 정책
- 퇴사자·전배자 명의로 등록된 출발지 IP 정책 (분기 1회 일괄 점검)

## 2. 해제 방법
1. ITSM 포털 → [서비스 요청] → [네트워크] → **방화벽 정책 해제** 양식을 작성합니다.
2. 정책 ID(방화벽 오픈 승인 메일에 기재)를 입력합니다. 모르면 인프라보안팀에 조회를 요청합니다.
3. 결재선: 요청자 → 시스템운영팀 검토 → 인프라보안팀 반영. 팀장 결재는 필요 없습니다.
4. 반영은 영업일 기준 1일 이내입니다.

## 3. 주의 사항
- 퇴사자 명의 정책은 원 신청자가 요청할 수 없으므로 시스템운영팀이 대리 신청합니다.
- 해제 전 해당 정책으로 동작하는 배치·인터페이스가 없는지 송미래 책임(배치 운영)에게 확인합니다.
