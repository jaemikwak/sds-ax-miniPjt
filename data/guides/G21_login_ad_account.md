# 원큐 로그인 문의 대응 — 법인 사용자 AD 계정(SECDS/CORP)과 계정 초기화

원큐는 AD(Active Directory) 계정으로 SSO 로그인합니다. 도메인이 두 개이고, 사용자 구분에 따라 써야 하는 도메인이 다릅니다.

| 사용자 구분 | 로그인 도메인 | 로그인 ID 형식 |
|---|---|---|
| 본사 임직원 | CORP | `CORP\사번` |
| **법인(계열사) 사용자** | **SECDS** | `SECDS\사번` |

## 1. 증상 A — "승인대기중입니다" 페이지가 나옴
- 원인: 법인 사용자가 **CORP AD 계정**으로 로그인한 경우입니다. 원큐에는 법인 사용자의 SECDS 계정만 등록되어 있어, CORP 계정은 미등록 사용자로 인식되어 "승인대기중입니다" 페이지로 이동합니다.
- 조치: 운영자 작업 없이 사용자가 직접 해결합니다.
  1. 브라우저를 모두 닫거나 원큐 우측 상단 [로그아웃]으로 CORP 세션을 종료합니다.
  2. 로그인 화면에서 `SECDS\사번`으로 다시 로그인합니다.
- 이 경우 계정 초기화는 하지 않습니다. 사용자에게 **템플릿 A**로 회신합니다.

## 2. 증상 B — SECDS AD 계정으로 로그인해도 안 됨
- 원인: 원큐 사용자 정보에 예전 CORP 계정이 잘못 매핑되어 있거나, AD 계정 정보가 바뀐 뒤 원큐 캐시가 남은 경우입니다.
- 조치: **운영자가 원큐 계정을 초기화**해야 합니다.
  1. 원큐 관리자 화면 → [사용자 관리] → 사번 검색 → **[계정 초기화]** 클릭(AD 매핑·로그인 캐시 삭제)
  2. 초기화 후 약 10분 뒤(SSO 캐시 만료) 사용자가 `SECDS\사번`으로 다시 로그인하도록 안내합니다.
  3. 초기화 이력은 관리자 화면 [변경 이력]에 자동 기록됩니다. 별도 결재는 필요 없습니다.
- 계정 초기화 후 사용자에게 **템플릿 B**로 회신합니다.
- 초기화 후에도 로그인이 안 되면 AD 계정 자체 문제일 수 있으므로 인프라보안팀(조은별 사원, 계정·접근권한 관리)에 확인을 요청합니다.

## 3. 답변 템플릿 메일

### 템플릿 A — CORP 계정으로 로그인해 "승인대기중"이 뜬 경우
```
제목: [원큐] 로그인 시 '승인대기중' 화면 안내

{요청자}님, 안녕하세요. 원큐 시스템운영팀 {운영 담당자}입니다.

'승인대기중입니다' 화면은 법인 사용자분이 CORP AD 계정으로 로그인하셨을 때 나타납니다.
법인 사용자분은 SECDS AD 계정으로 로그인하셔야 합니다.

1. 원큐 우측 상단 [로그아웃]을 누르거나 브라우저를 모두 닫아 주세요.
2. 로그인 화면에서 SECDS\사번 으로 다시 로그인해 주세요.

SECDS 계정으로도 로그인이 안 되면 회신 주시면 계정 초기화를 진행해 드리겠습니다.
참고: ONEQOPS > Support > Login-AD-Account

감사합니다.
```

### 템플릿 B — SECDS 계정으로도 로그인이 안 되어 계정 초기화를 한 경우
```
제목: [원큐] 계정 초기화 완료 안내

{요청자}님, 안녕하세요. 원큐 시스템운영팀 {운영 담당자}입니다.

요청하신 원큐 계정을 초기화했습니다.
약 10분 뒤(로그인 캐시 만료 후) SECDS\사번 으로 다시 로그인해 주세요.

초기화 후에도 로그인이 안 되면 AD 계정 확인이 필요하니 회신 부탁드립니다.
참고: ONEQOPS > Support > Login-AD-Account

감사합니다.
```
