# 운영 SSL 인증서 교체 절차

원큐 **운영** 도메인(`oneq.example.com`)의 SSL 인증서를 교체하는 절차입니다.
개발·스테이징 인증서는 G04를 참고하세요. 운영 서버 구성은 G17을 참고하세요.

## 1. 일정
- 인증서 만료 **30일 전** 인프라보안팀(이도윤 선임)이 갱신 인증서(.pfx)를 발급해 전달합니다.
- 교체 작업은 만료 **7일 전까지** 정기 작업 시간(화·목 22:00~24:00)에 수행합니다.

## 2. 작업 절차 (무중단, 한 대씩)
1. 변경관리(ITSM) 작업계획서를 등록하고 운영팀장(윤재석 팀장) 승인을 받습니다.
2. 갱신 인증서(.pfx)와 체인 인증서를 인증서 보관함(`\\secure\cert\oneq\2026`)에서 내려받습니다.
3. L4에서 `ONEQ-PRD-01`을 서비스 제외합니다.
4. `ONEQ-PRD-01`에 점프서버로 RDP 접속 → 인증서를 [로컬 컴퓨터 > 개인] 저장소에 가져오기 → IIS 관리자에서 사이트 **443 바인딩**의 인증서를 새 인증서로 변경합니다.
5. `https://ONEQ-PRD-01` 직접 호출로 만료일을 확인한 뒤 L4에 복귀시킵니다.
6. `ONEQ-PRD-02`에 3~5단계를 반복합니다. L4에 인증서가 걸려 있다면 L4 인증서도 함께 교체합니다.
7. 작업 완료 후 작업계획서에 결과를 등록하고, 인프라보안팀에 교체 완료를 회신합니다.

## 3. 롤백
- 접속 오류 발생 시 IIS 바인딩을 기존 인증서로 즉시 되돌립니다(기존 인증서는 저장소에서 삭제하지 말 것).
