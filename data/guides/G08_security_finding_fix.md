# 서버 보안 취약점 점검 결과 조치 절차

인프라보안팀의 정기 취약점 점검(반기 1회) 결과를 받은 뒤 운영팀이 조치하는 절차입니다.

## 1. 점검 결과 수신
- 인프라보안팀이 서버별 취약 항목 엑셀을 메일로 전달합니다. 기준 항목은 G07(보안 기준)입니다.

## 2. 조치 기한
- 상(High) 항목: **7일 이내**, 중(Medium): 30일 이내, 하(Low): 다음 정기 작업 시
- 기한 내 조치가 어려우면 예외 신청서(사유·대체 통제)를 인프라보안팀에 제출합니다.

## 3. 조치 절차
1. 항목별 조치 방법을 확인하고, 운영서버는 변경관리 작업계획서를 등록합니다.
2. 조치 후 증적(설정 화면 캡처, 명령 결과)을 수집합니다.
3. 조치 결과서를 인프라보안팀 점검 담당자에게 회신합니다. 담당자가 이행 점검 후 종결합니다.
