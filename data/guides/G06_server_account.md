# 원큐 서버 계정·점프서버 접근 신청

방화벽이 열려 있어도 서버 Windows 계정이 없으면 RDP로 로그인할 수 없습니다. 서버 계정과 점프서버 접근 신청 방법입니다.

## 1. 개발·스테이징 서버 계정
1. ITSM → [계정/권한] → **서버 계정 신청**에서 대상 서버(`ONEQ-DEV-01`, `ONEQ-STG-01`)와 계정 유형(개인 도메인 계정 로그온 허용)을 선택합니다.
2. 결재선: 신청자 → 소속 팀장 → 시스템운영팀 확인 → 인프라보안팀(조은별 사원) 생성.
3. 반영까지 영업일 기준 1일, 기존 사내 도메인 계정으로 RDP 로그인합니다.

## 2. 운영서버 접근(점프서버)
- 운영서버(`ONEQ-PRD-01/02`, `ONEQ-PRD-DB01`)는 점프서버 `JUMP-PRD01` RDP 경유만 허용되며, 접근 시 작업계획서 번호가 필요합니다.
- 점프서버 계정은 분기마다 재승인이 필요합니다.

## 3. 참고
- 방화벽 오픈은 G01, 퇴사자 계정 회수는 인프라보안팀이 인사 연동으로 자동 처리합니다.
