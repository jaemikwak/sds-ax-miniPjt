# 원큐 정기릴리즈 결재라인

매월 정기릴리즈 반영 전에 올려야 하는 결재와 결재선입니다. 긴급릴리즈는 G13을 따릅니다.

## 1. 결재 상신자
- 시스템운영팀 원큐 운영 담당자(현재 정하늘 선임)가 상신합니다.

## 2. 결재선 (순서대로)
1. 상신: 시스템운영팀 운영 담당
2. 검토: 품질관리팀 정기릴리즈 PM(한지민 책임) — 통합 테스트 결과 첨부 확인
3. 승인: 품질관리팀장(신동욱 팀장) — 품질 승인
4. 최종 승인: 시스템운영팀장(윤재석 팀장) — 운영 반영 승인

## 3. 첨부 필수
- 릴리즈 기능 목록(G14 형식), 통합 테스트 결과서, 롤백 계획

## 4. 기한
- 반영일 **전 영업일 18:00까지** 최종 승인이 완료되어야 합니다. 미완료 시 반영은 다음 달로 이월됩니다.
